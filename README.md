# emusoi/tap

Homebrew formulae for [emusoi](https://github.com/emusoi) tools.

```sh
brew install emusoi/tap/buni
```

| Formula | What it is |
|---|---|
| `buni` | [buni](https://github.com/emusoi/buni): design tools for agents and people (the .buni format, a design agent, CLI and MCP server). |

Formulae are written by each project's release workflow; changes to them belong in that project.
